Export the measuring module behind the agent tools as `@tenphi/glaze/harness/measure`, with types. `inspectTheme`, `inspectColor`, `filterThemes`, `missesOf` and `measurePair` measure a theme, a single color or a pair the way the contrast solver does, so other tools, such as a design system's token lookup, can build on them. See "Measuring module" in the Utilities reference.
